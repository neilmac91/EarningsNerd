## Evidence conventions and limits

Every .json records capture time, final URL, theme class, root font, viewport, document width, headings, main count, fixed/sticky chrome, every visible muted text node and up to600 direct text nodes with resolved type, colour, spacing and composited contrast. Alpha backgrounds are composited using the same algorithm as frontend/tests/e2e/fixtures/contrast.ts. A caveat marks gradients or ancestor opacity. Disabled CTA ink is not reported as a WCAG text failure. PNGs are originals in scratch; the report author selects and downscales evidence.

The normal visit stores essential-only consent before navigation; first-visit captures use a fresh context. Home/pricing/filing/company/login/register each have both first-visit and post-consent desktop/phone captures in both themes (the home1440 first-visit originals were produced by the root agent before this walk). Scroll-triggered entrances are activated before full capture. The filing coachmark is present where a fresh post-consent visitor sees it. Extra interactions are recorded in public-interactions.json.

## What worked

Muted token text on ordinary loaded route grounds had minimum measured contrast 4.8:1 in light and 4.98:1 in dark. The probe parses the rendered foreground, composites ancestor backgrounds, and uses the WCAG luminance formula. This does not establish all colors, all opacity stacks or occluded text behind overlays. No generic muted-text or dark-inversion failure was reproduced.

Analysis's captured fixture renders the picker, four KPIs, charts, metrics table, expanded data notes and narrative in both themes. Its 390px root32 screen stays within390px and both themes yield zero running Web Animations under reduced motion. Chart and table horizontal scroll is internal. The existing prose/table/source separation survives the narrow view. Export PDF, Refresh analysis and Export Excel controls were present; downloads and generated export file fidelity were not tested. Chart and narrative captures are `analysis-revenue-growth-*`, `analysis-ai-trend-analysis-*`, `analysis-the-trajectory-*`; metrics and notes have corresponding filenames.

Source and Ask preserve their different reading registers, and the shared modal styles remain recognizable through feedback, upgrade, verification and calendar states. The verified filing prose, Ask answer and citations came from the repository's filing fixture or the owning citation keyboard spec. Their evidence is a fixture rendering check, not a claim about a genuine production answer.
