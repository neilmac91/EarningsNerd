# Retaining a compacted source-review attempt

An eligible replacement brief must not erase findings from an earlier incomplete review.
Schema-2 prerequisites may carry `ai_assisted.adverse_source_evidence` alongside the ordinary
eligible pair and reconciliation. The ordinary nine-field issue shape and current-pair
dispositions stay unchanged. When this optional field is absent, the inventory format is unchanged.

This bounded format supports the observed compacted `source_reference_b` record. It does not
certify other terminal statuses, source-A retries, complete provider history or programme admission.
Do not relabel a different history to make it fit. Register every known retired source context
before sealing the programme inventory; the validator cannot discover an omitted external attempt.
The execution journal's separately retained authority addresses newly dispatched attempt history.

Each row declares its accession, retired role/context, current reconciliation context and terminal
status `compacted_ineligible`, plus `{path, sha256}` records for these nine artifacts:

1. The retired prompt.
2. The original draft.
3. Its narrative.
4. Its read log.
5. Its status addendum.
6. The custodian's retirement decision.
7. The actual reconciliation prompt.
8. Its pre-dispatch reservation.
9. The separate adverse-disposition ledger.

The addendum must name exactly the original draft, narrative and read log. Original absolute
locations are historical labels; the row's copied artifacts supply the hash-bound bytes. The
reservation binds the governing protocol prompt, actual prompt, eligible A/B hashes and current
reconciliation context, declares no candidate inputs and records no admission approval. It is
retained operator evidence, not an independently authenticated provider attestation.

The separate ledger gives every retired issue exactly one supported, rejected or unresolved
disposition. A supported row names a current reconciled issue. Every row includes a source
locator, reason and a role/hash from the same accession's frozen source packets. A reconciler
may correct the earlier source-role choice; that reattribution is surfaced as a limitation.
Unresolved findings hold readiness. No source findings are rewritten or judged again by validation.

The inventory binds all nine artifact bytes. A later coherent rewrite, including an updated
inline hash, differs from the sealed inventory. The shared source-context closure includes the
retired context so it cannot serve as either blind quality reviewer or source challenger.
These checks preserve declared custody and role separation; they do not establish financial
correctness, complete model attention or independence from unknown external exposure.

Context receipts inside eligible briefs/reconciliations may use the original prerequisite-root
paths or a path relative to the owning artifact. Resolution checks both contained locations.
If both exist with different bytes, validation rejects the ambiguity. Identical copies retain
the legacy root choice. Frozen briefs and their input hashes need not be rewritten to relocate
the artifact with its sibling receipt.

The H29 integration smoke uses actual immutable source-review artifacts, including 25 current
and 15 retired dispositions. Its one-accession manifest and any undispatched placeholder role
contracts are explicitly a fixture. It exercises protocol validation, inventory and context
closure; it does not substitute for the approved 30-filing readiness, paid generation, blinded
review, Fable judgments or final E7 decision.
